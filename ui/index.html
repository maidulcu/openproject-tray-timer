              What this app records

              While a timer runs, it asks the operating system how long it has been since the last mouse or keyboard input. After the limit above it stops the timer at the moment input stopped, and asks you when you are back whether that time was work. During work hours with no timer running, it reads the same "time since last input" every 30 seconds to decide on a reminder, and stores nothing. It never records keystrokes, what you type, screenshots, window titles or which apps you use.

              OpenProject only receives the time entries you start, stop or add, with your comment. The API key is kept in the system keyring, not in a file.
